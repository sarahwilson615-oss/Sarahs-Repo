# MLS export guide — Port Aransas residential

## What to export

| File | Filters |
|------|---------|
| Residential — Active | City/ZIP Port Aransas (78373); Residential; Status = Active |
| Residential — Sold | Same area; Residential; Sold/Closed; **Close Date = your report range** |
| Prior-year sold (optional) | Same close-date month last year |

Include columns: **Housing Type**, **Condo Type**, List Price, **Selling Price** (sold), DOM if available, Address.

## Sold date ranges

Prefer a calendar close-date range (e.g. Jun 1–Jun 30). Label the report to match.

## Matrix tips

1. Save searches: **PA Residential Active** and **PA Residential Sold**.
2. Avoid marketing-only exports that omit Selling Price.
3. Unnamed early columns (MLS# / Status) are handled automatically.
