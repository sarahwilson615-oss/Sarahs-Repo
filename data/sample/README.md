# Sample MLS CSVs

These demo files mirror the column layout expected by the report tool. Replace them with your real Port Aransas MLS exports (same column names when possible).

| File | Contents |
|------|----------|
| `sold_2026-06.csv` | Closed sales in Port Aransas, June 2026 |
| `sold_2025-06.csv` | Closed sales in Port Aransas, June 2025 (YoY) |
| `active_2026-06.csv` | Active listings as of end of June 2026 |
| `active_2025-06.csv` | Active listings as of end of June 2025 (YoY) |

Required columns are listed in [`docs/csv-schema.md`](../../docs/csv-schema.md).
